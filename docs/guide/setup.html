クイックスタート

開発対象のプロジェクトで、設計・実装・評価を実行する手順です。

前提

Claude Code、Playwright MCP、開発対象のプロジェクトを用意してください。対象アプリの起動コマンドとURLが必要です。

内容を確認した信頼できるプロジェクトで使用し、Claude Codeの権限確認を無効にしないでください。仕様書やスプリント資料に認証情報を記載せず、Evaluatorには信頼できる対象アプリのURLだけを渡してください。

1. ハーネスをインストールする

Claude Code 内で実行します。

/plugin marketplace add satoshi-yamamoto-dev/harness-agent-loop
/plugin install agent-loop@harness-tools

2. 対象プロジェクトを準備する

対象プロジェクトの CLAUDE.md に、目的、技術スタック、開発サーバーの起動コマンドとURLを記載します。Playwright MCPは /mcp で接続を確認してください。

3. 実装を依頼する

対象プロジェクトでClaude Codeを開き、要求を渡します。

/agent-loop:start タスク管理アプリを作りたい。
期限と優先度で整理でき、スマートフォンでも使いやすくしてください。

仕様を確認して承認すると、契約作成、実装、評価の順に進みます。

4. 実行結果を確認する

docs/010_製品仕様書/spec.md と docs/020_スプリント/sprint-N.md、実装されたアプリ、Evaluatorの判定を確認します。
