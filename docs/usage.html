各機能の使い方

start Skill は開発対象プロジェクトで使用します。成果物はそのプロジェクトに保存されます。

Claude Code の操作

新しい開発を開始する

/agent-loop:start メモの追加・編集・削除とキーワード検索ができるWebアプリを作ってください。

既存のスプリントを再開する

/agent-loop:start Sprint 1 を再開してください。既存の仕様と契約を確認してください。

Claude Code 版には agent-loop:planner、agent-loop:generator、agent-loop:evaluator の3エージェントが登録されます。接続を確認するには /agents、Playwright MCP は /mcp を使います。

アンインストール

claude plugin uninstall --scope user agent-loop@harness-tools

Skill が見つからない場合は claude plugin list で有効化を確認し、Claude Code を再起動してください。

Codex の操作

新しい開発を開始する

$agent-loop:start メモの追加・編集・削除とキーワード検索ができるWebアプリを作ってください。

既存のスプリントを再開する

$agent-loop:start Sprint 1 を再開してください。既存の仕様と契約を確認してください。

Codex 版では3つの役割定義を Skill が参照します。サブエージェント機能が利用できる場合は各役割へ作業を渡し、利用できない場合は段階ごとに役割を切り替えます。ブラウザ評価には利用環境のブラウザ操作手段を使用します。

無効化・削除

ターミナルで削除する場合は次を実行します。Skill が見つからない場合はインストールと有効化を確認し、新しいタスクで試してください。

codex plugin remove agent-loop@harness-tools-codex

共通の開発フロー

  1. Planner が製品仕様書とスプリント計画を作る。ユーザーは仕様の方向性を確認する。
  2. Generator がテスト可能なスプリント契約を起票する。
  3. Evaluator が契約の仕様適合、テスト可能性、曖昧さ、矛盾をレビューする。
  4. 承認された契約に従い、Generator が機能と UI を実装する。
  5. Evaluator が起動したアプリを操作し、契約とデザインを評価する。不合格なら修正と再評価を行う。

評価基準

Evaluator は契約条件と、空状態・長い入力などのエッジケース、コンソールエラーを確認します。契約条件を満たさない場合は不合格です。ブラウザで実操作できなかった条件は未検証として記録します。

デザイン基準合格点
デザインの質6/10以上
オリジナリティ6/10以上
クラフト5/10以上
機能性7/10以上

不合格の場合は具体的な修正指示を Generator に戻します。3回連続で不合格になった場合はループを停止し、ユーザーに方針を確認します。
