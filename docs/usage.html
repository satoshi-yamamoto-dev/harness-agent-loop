各機能の使い方

start Skill は開発対象プロジェクトのルートで使用します。プラグインのインストール先へ成果物を書き込む必要はありません。

できること

  • 短い要求から製品仕様書とスプリント計画を作る
  • 実装前にテスト可能な完了条件を起票・レビューする
  • 機能とUIを一つのスプリントとして実装する
  • Playwrightによる機能テストとデザイン評価を行う
  • 評価で見つかった問題を修正し、再評価する

1. 新しい開発を開始する：start Skill

/agent-loop:start メモの追加・編集・削除とキーワード検索ができるWebアプリを作ってください。

要求には、利用者、必要な操作、保存したいデータ、完成時に確認したいことを含めると、仕様を具体化しやすくなります。Skill はスラッシュコマンドで明示的に実行できるほか、関連する依頼に応じて Claude が自動的に選択できます。

2. 既存のスプリントを再開する

/agent-loop:start Sprint 1 を再開してください。既存の仕様と契約を確認してください。

Skill は既存の CLAUDE.md、製品仕様書、スプリント資料を確認してから、オーケストレーション手順の該当ステップへ戻ります。

3. 仕様とスプリント計画を確認する

ファイル内容
docs/010_製品仕様書/spec.mdプロダクト方針、機能、技術設計
docs/020_スプリント/README.md全スプリントと各Stepの進捗（メインエージェントが更新）
docs/020_スプリント/sprint-N.mdスプリントの機能、ゴール、完了条件、Evaluatorの判定詳細

Planner が作成した仕様は、ユーザーが承認するまで実装へ進みません。

4. スプリント契約を合意する

Generator が5〜15個を目安に、機械的に確認できる完了条件を起票します。Evaluator は仕様適合、テスト可能性、曖昧さ、矛盾を確認します。差し戻された場合は、承認されるまで契約を修正します。

5. 実装とUIを完成させる

契約承認後、Generator が機能とUIを実装します。スタブやTODOを残さず、契約条件ごとに自己テストを行い、完了報告を作成します。

6. アプリを評価する

対象アプリを起動し、評価時にURLを渡します。Evaluator は契約条件、空状態や長い入力などのエッジケース、コンソールエラーを確認します。

デザイン基準合格点
デザインの質6/10以上
オリジナリティ6/10以上
クラフト5/10以上
機能性7/10以上

不合格の場合は具体的な修正指示を Generator に戻し、評価をやり直します。3回連続で不合格になるとループを停止し、ユーザーに方針を確認します。

7. アンインストールする

ターミナルで次のコマンドを実行すると、ユーザー単位でインストールしたハーネスをアンインストールできます。

claude plugin uninstall agent-loop@harness-tools --scope user

完了後、次のコマンドを実行し、一覧に agent-loop@harness-tools が表示されないことを確認します。

claude plugin list
アンインストールしても、ハーネスで作成・更新したプロジェクトのソースコードや docs、このリポジトリの作業コピーは削除されません。

エージェント名

登録名役割
agent-loop:planner仕様書とスプリント計画
agent-loop:generator契約起票、機能とUIの実装
agent-loop:evaluator契約レビュー、機能とデザインの評価

困ったとき

症状確認すること
start Skillが見つからない/plugin で有効化を確認し、Claude Codeを再起動する
エージェントが見つからない/agents で agent-loop: 接頭辞の登録名を確認する
ブラウザ評価ができない/mcp の接続、対象アプリの起動、URLへの到達を確認する
期待したステップから始まらない依頼文に新規開発か再開か、対象のSprint番号を明記する
オーケストレーション手順は skills/start/SKILL.md に含まれ、プラグインと一緒にインストールされます。別のrulesファイルを読み込む必要はありません。
