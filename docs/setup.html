クイックスタート

開発対象のプロジェクトと、そのアプリの起動コマンド・URLを用意してください。使用する製品を選ぶと、対応する導入手順が表示されます。

内容を確認した信頼できるプロジェクトで使用してください。仕様書やスプリント資料に認証情報を記載せず、Evaluator には信頼できる対象アプリの URL だけを渡してください。

Claude Code で使う

1. インストール

ターミナルで次を実行します。マーケットプレイスとプラグインはいずれもユーザースコープです。

claude plugin marketplace add --scope user satoshi-yamamoto-dev/harness-agent-loop
claude plugin install --scope user agent-loop@harness-tools

必要に応じて Playwright MCP を追加します。

claude mcp add playwright npx @playwright/mcp@latest

インストール済みのプラグインは claude plugin list、MCP の接続状態は Claude Code 内の /mcp で確認できます。

2. 開始

対象プロジェクトで Claude Code を開き、次のように依頼します。

/agent-loop:start タスク管理アプリを作りたい。
期限と優先度で整理でき、スマートフォンでも使いやすくしてください。

Codex で使う

1. インストール

ターミナルでマーケットプレイスとプラグインを追加します。

codex plugin marketplace add satoshi-yamamoto-dev/harness-agent-loop
codex plugin add agent-loop@harness-tools-codex

ブラウザ評価には、Codex の利用環境で使えるブラウザ操作手段と起動済みの対象アプリが必要です。ブラウザで操作できない条件は未検証として扱います。

2. 開始

対象プロジェクトの Codex の入力欄で、Skill 名と依頼を入力します。次の行はシェルコマンドではありません。

$agent-loop:start タスク管理アプリを作りたい。
期限と優先度で整理でき、スマートフォンでも使いやすくしてください。

3. 実行結果を確認する

docs/010_製品仕様書/spec.md と docs/020_スプリント/sprint-N.md、実装されたアプリ、Evaluator の判定を確認します。仕様を確認して承認すると、契約作成、実装、評価の順に進みます。
