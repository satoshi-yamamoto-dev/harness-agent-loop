## 更新ルール

- 更新はメインエージェントが行う。
- Step 5 の合格後、ルートの README から一覧行と詳細表を移し、契約ファイルを同じフォルダへ移す。リンクを新しい場所に合わせる。
- 完了済みスプリントを再開する場合は、一覧行・詳細表・契約ファイルをルートへ戻してから進捗を更新する。
